# 🍃 Sobre o Projeto — É Melhor Falar

**É Melhor Falar** é um projeto de **Trabalho de Conclusão de Curso (TCC)** desenvolvido por alunos do **3º ano do curso de Desenvolvimento de Sistemas** da  
**ETEC Vasco Antônio Venchiarutti (ETECVAV)**.

O projeto propõe o desenvolvimento de uma **plataforma digital de apoio e conscientização**, onde pessoas que sofrem preconceito ou discriminação possam:

- Compartilhar relatos e experiências
- Encontrar apoio e orientação
- Recomendar lugares seguros e inclusivos
- Acessar informações sobre direitos e canais oficiais de denúncia

Nosso objetivo é utilizar a **tecnologia como ferramenta de impacto social**, promovendo informação, acolhimento e conscientização.

## 🎯 Objetivo do Projeto

Desenvolver uma plataforma web que permita:

- 🗣 Compartilhamento de relatos e apoio entre usuários  
- ⭐ Recomendações de lugares seguros e inclusivos  
- ⚖ Acesso a informações sobre direitos e orientação legal  
- 📩 Envio de denúncias privadas para análise administrativa
